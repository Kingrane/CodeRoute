> **CodeLingo** — игровой сервис для изучения программирования: короткие задания, очки, жизни и разбор ошибок.
> Курс построен как дерево уровней, а каждое задание — мини-игра: собрать программу из перемешанных строк, найти строку с ошибкой, угадать вывод.
> Объяснения ошибок и новые задания на слабые темы будет подсказывать ИИ-ассистент.
