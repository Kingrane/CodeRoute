# Дизайн-система

Все токены живут в `src/index.css` в блоке `@theme`, шрифты подключены в `index.html`.
В компонентах — только классы Tailwind и эти токены. Hex в разметке не пишем никогда:
поменять цвет потом можно в одном месте.

## Цвета

| Токен | Классы | Значение | Где использовать |
|---|---|---|---|
| `ink` | `bg-ink` `text-ink` | `#1c1c1e` | основной текст, тёмные блоки, главная кнопка |
| `ink-soft` | `bg-ink-soft` | `#3a3a3d` | тёмные поверхности второго уровня |
| `muted` | `text-muted` | `#6f6f74` | подписи, вторичный текст, номера уроков |
| `paper` | `bg-paper` | `#f3f3f1` | фон страницы |
| `surface` | `bg-surface` | `#ffffff` | карточки, шапка, панели |
| `line` | `border-line` | `#e4e4e1` | бордеры, разделители, неактивные полоски |
| `accent` | `bg-accent` `text-accent` | `#ff6b1a` | главное действие на экране, активный шаг |
| `accent-soft` | `bg-accent-soft` | `#ffe6d8` | подложка под акцент, подсветка карточки |
| `success` | `bg-success` `text-success` | `#2fbf71` | «пройден», верный ответ |
| `warning` | `bg-warning` `text-warning` | `#f2b705` | «следующий», предупреждение |
| `info` | `bg-info` `text-info` | `#4a6cf7` | ссылки, служебные акценты |
| `violet` | `bg-violet` | `#7c5cfc` | плитки уроков, декоративные метки |

Плитки уроков идут по порядку: `violet` → `success` → `accent` → `warning` → `info`.

## Шрифты

| Роль | Токен | Шрифт |
|---|---|---|
| Заголовки, крупные цифры | `font-display` | Unbounded 600–900 |
| Текст и интерфейс | `font-sans` | Golos Text 400–700 |
| Код, номера строк | `font-mono` | JetBrains Mono 400/600 |

Размеры (примерно, Tailwind-классами):

| Роль | Класс | Где |
|---|---|---|
| Первый экран | `text-4xl sm:text-6xl` + `font-display` | лендинг, заголовок курса |
| Заголовок секции | `text-2xl sm:text-3xl` + `font-display` | «Как проходит урок», «Твой маршрут» |
| Заголовок карточки | `text-lg font-semibold` | названия уроков |
| Текст | `text-base` | описания, подсказки |
| Подпись | `text-sm text-muted` | «5 уроков · 20 заданий» |

Заголовки уже получают `font-display` из базового слоя — для `h1`, `h2`, `h3` класс не нужен.
Для не-заголовочных крупных надписей добавляй `font-display` руками.

## Радиусы и тени

| Токен | Класс | Значение | Где |
|---|---|---|---|
| `radius-card` | `rounded-card` | 16px | карточки, окна-мокапы, панели |
| `radius-pill` | `rounded-pill` | 999px | кнопки, чипы, меню-«пилюля» |
| `shadow-card` | `shadow-card` | мягкая тень | плавающие панели: меню, окно «Как проходит урок» |

Вложенные элементы внутри карточки — `rounded-xl` или меньше, но не больше карточки.

## Правила

1. **Один акцент на экран.** Оранжевая кнопка — одна, это главное действие. Остальные кнопки — `ink` или контурные.
2. **Светлый фон по умолчанию.** `paper` для страницы, `surface` для карточек. Тёмный блок (`ink`) — только для шапки курса и подобных «обложек».
3. **Текст на тёмном** — `surface` или `paper`, приглушённый — `muted` не темнее 60% белого.
4. **Не хардкодим hex** и не добавляем новые цвета «на один раз». Нужен новый — сначала токен в `index.css`, потом использование.
5. **Не добавляем библиотеки ради стилей.** Только Tailwind и токены.
6. **Мобильный первым.** Всё проверяем на 360px: заголовки не больше `text-4xl`, длинные строки кода переносятся, а не вылезают.
