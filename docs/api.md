# API

Базовый адрес: в разработке `http://localhost:5070` через прокси Vite, на проде — переменная `VITE_API_URL`.

## GET /api/health

```json
{ "status": "ok" }
```

Нужен, чтобы Render не засыпал (UptimeRobot пингует каждые 5 минут).

## GET /api/courses/python

Список уроков для карты курса. Без заданий.

```json
{
  "lessons": [
    {
      "id": "lesson-01",
      "order": 1,
      "title": "Первый вывод",
      "description": "print, переменные, строки",
      "taskCount": 4
    }
  ]
}
```

## GET /api/lessons/{id}

Один урок с заданиями. Строки перемешаны, правильного порядка здесь нет.

```json
{
  "id": "lesson-01",
  "order": 1,
  "title": "Первый вывод",
  "tasks": [
    {
      "id": "l01-t1",
      "prompt": "Собери программу, которая выводит «Привет!»",
      "lines": ["print(message)", "message = \"Привет!\""]
    }
  ]
}
```

Если урока нет — `404` и `{ "error": "Урок не найден" }`.

## POST /api/lessons/{id}/check

Проверка ответа. Правильный порядок остаётся на сервере.

Запрос:

```json
{ "taskId": "l01-t1", "lines": ["message = \"Привет!\"", "print(message)"] }
```

Верно:

```json
{ "correct": true, "explanation": "Python выполняет строки сверху вниз...", "pointsDelta": 10, "livesDelta": 0 }
```

Неверно:

```json
{ "correct": false, "hint": "Сначала переменной нужно присвоить значение.", "pointsDelta": -3, "livesDelta": -1 }
```

## Правила начисления

- верно с первой попытки: +10;
- ошибка: −3 очка (минимум +3 за задание) и −1 жизнь;
- 5 жизней на попытку урока, 0 жизней — урок заново;
- урок без ошибок: бонус +20.

## Ограничения

- правильный порядок (`solution`) не отдаётся ни в одном ответе;
- очки и жизни считает только сервер;
- прогресс хранится в браузере (localStorage), на сервере пользователей нет.
