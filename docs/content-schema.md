# Формат урока

Файл: `content/python/lesson-01.json`. Автор пишет **правильную программу сверху вниз** —
сервер сам перемешает строки.

## Структура

```json
{
  "id": "lesson-01",
  "order": 1,
  "title": "Первый вывод",
  "description": "print, переменные, строки",
  "tasks": [
    {
      "id": "l01-t1",
      "prompt": "Собери программу, которая выводит «Привет, CodeRoute!»",
      "solution": [
        "message = \"Привет, CodeRoute!\"",
        "print(message)"
      ],
      "hint": "Сначала переменная получает значение, только потом её можно напечатать.",
      "explanation": "Python выполняет строки сверху вниз. print(message) сработает только после того, как message уже создана."
    }
  ]
}
```

## Поля

| Поле | Обязательно | Правило |
|---|---|---|
| `id` | да | `lesson-01`, по порядку, без пропусков |
| `order` | да | число, совпадает с номером в `id` |
| `title` | да | до 40 символов, без точки в конце |
| `description` | да | одна строка, до 60 символов |
| `tasks` | да | ровно 4 задания |
| `tasks[].id` | да | `l01-t1` … `l01-t4` |
| `tasks[].prompt` | да | что должна делать программа, одно предложение |
| `tasks[].solution` | да | 3–7 строк в правильном порядке |
| `tasks[].hint` | да | почему неверно и куда смотреть, 1–2 предложения |
| `tasks[].explanation` | да | почему правильно, 1–2 предложения |

## Требования к заданию

1. Внутри одного задания **нет двух одинаковых строк** — иначе проверка порядка ломается.
2. Правильный порядок **ровно один**. Если строки можно переставить и программа всё равно работает — задание плохое.
3. Каждая строка `solution` — самостоятельная строка кода, без переносов.
4. Программа запускается в Python 3 без ошибок.
5. `input()` использовать нельзя — код в браузере не вводит данные. Бери готовые значения.
6. Тема задания соответствует названию урока.

## Проверка перед сдачей

```powershell
python -c "import json; d=json.load(open('content/python/lesson-01.json',encoding='utf-8')); [print('---',t['id'],'\n'+'\n'.join(t['solution'])) for t in d['tasks']]"
```

Каждая программа должна выполниться. Потом пройди урок в приложении руками.
